# Customer metric cards + trend

## Context
The customer portal currently shows only the image and comment. Now it should
display metric cards (weight, muscle, body-fat%, score) with Δ deltas vs. the
prior measurement, and a body-fat trend sparkline over the last 7 records.
Uses `withDeltas` from lib/measurement.ts. Advances Phase 3 exit criteria.

## Goals
- Each record shows an `IB-<id>` key + measured_on date
- Metric cards show current value + ▲▼ delta (skipped if no prior or no value)
- Body-fat trend: bar sparkline over last 7 records at the top of the page
- Graceful empty state if metrics are all null
