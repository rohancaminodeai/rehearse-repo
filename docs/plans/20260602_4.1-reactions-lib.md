# Reactions lib + db layer (TDD)

## Context
Customers can leave emoji reactions on their own measurements. The business rule
is strict: a customer may only react to a record that belongs to them (anti-IDOR,
B4). The allowed emoji set is an allowlist. Advances Phase 4 exit criteria.

## Goals
- `ALLOWED_EMOJI` constant + `validateReaction(emoji)` helper
- `db.toggleReaction(customerId, recordId, emoji)` — inserts or deletes, verifying ownership
- `db.getReactions(recordId)` — returns `{emoji, count}[]`
- ≥ 6 TDD cases: owner toggles on/off, non-owner blocked, invalid emoji rejected

## Business-rule check
- B4 IDOR: SQL `WHERE EXISTS (SELECT 1 FROM records WHERE id=$recordId AND customer_id=$customerId)`
  executed inside toggleReaction — ownership verified at DB layer, not just application layer
