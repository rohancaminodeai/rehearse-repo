# Trainer metrics form

## Context
Extends the trainer upload form to accept the 4 optional metrics and a
measurement date. Wires `validateMeasurement` in the server action so invalid
ranges are rejected with a friendly error. `addRecord` signature extended to
accept metric fields. Advances Phase 3.

## Goals
- `addRecord` accepts weight/skeletal_muscle/body_fat_pct/inbody_score/measured_on
- `addRecordAction` calls `validateMeasurement`; invalid → redirect with error
- Trainer form shows 4 optional number inputs + a date picker

- Styling (task 6.1)
