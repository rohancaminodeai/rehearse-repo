# Upload validation

## Context
`accept="image/*"` on the form is client-only. A malicious or careless user
could POST any file; the server must enforce size and type. Advances Phase 1.

## Goals
- `validateUpload({name, size})` returns a user-facing error string or `null`
- Rejects: empty, > 5 MB, non-image extension
- 4 TDD cases: valid PNG, empty, oversized, non-image extension
