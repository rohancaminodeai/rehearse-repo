# Image serving route

## Context
Images are stored in `UPLOAD_DIR` (a Docker volume), not in `public/`. A route
handler streams them. Must be safe against path-traversal attacks. Advances Phase 2.

## Goals
- `GET /uploads/<name>` streams the file from `UPLOAD_DIR`
- Returns correct `Content-Type` per extension (PNG, JPG, GIF, WebP)
- Returns 404 for unknown files
- Path traversal blocked: `name.replace(/[^\w.-]/g, '')` strips separators

## Security note
Stripping `/`, `\`, and `..` from the filename before joining with `UPLOAD_DIR`
means `../../../etc/passwd` is reduced to `etcpasswd` — a harmless non-existent
filename. The `UPLOAD_DIR` prefix is never escaped.

- **What changed:** `app/uploads/[name]/route.ts` (21 LOC)
- **Outcome:** image serving verified 200 in Docker; unknown file → 404; traversal safe
