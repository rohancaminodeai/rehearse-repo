# HMAC session

## Context
Customer sessions must be forgery-proof — a customer must not be able to craft
a cookie that identifies them as a different customer. Advances Phase 1.

## Goals
- `sign(id)` produces a cookie value `"<id>.<hmac>"`
- `verify(cookie)` returns the id only if the HMAC matches; otherwise `null`
- Uses `timingSafeEqual` to prevent timing attacks

## Summary
- **What changed:** `lib/session.ts` (18 LOC)
- **Outcome:** forged cookie (wrong HMAC) verified to return `null` in manual test
