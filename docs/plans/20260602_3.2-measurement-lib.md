# Measurement validation + deltas (pure logic, TDD)

## Context
Pure business-logic layer for measurements: validate trainer-supplied metric
ranges and annotate a records array with Δ deltas vs. the previous record.
No DB or HTTP — fully testable with pg-mem or plain objects. Advances Phase 3.

## Goals
- `validateMeasurement(input)` returns an error string or null
- `withDeltas(records[])` annotates each record with Δ vs. the prior record
- ≥ 8 TDD cases cover all range edges and delta calculation
